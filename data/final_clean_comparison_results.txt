Clean KiD-Python controlled comparison
======================================

Matched setup:
- Initial temperature: 283.15 K
- Initial qv: 0.0073923 kg kg-1
- Aerosol number concentration: 50e6 m-3
- Imposed cooling rate: 0.001 K s-1

- KiD rain sedimentation disabled

  Python maximum is approximately 70% higher.

Interpretation:
Under the clean matched-cooling configuration, KiD develops cloud
water earlier and maintains supersaturation very close to zero,
whereas the Python Maxwell-growth model permits a substantially
larger transient supersaturation and ultimately produces more
maximum cloud water.

Source-code inspection provides a physical explanation for this
difference. The Python model uses explicit Kohler activation followed
by finite-rate Maxwell droplet growth. Thompson09 instead applies a
Newton-Raphson saturation-adjustment treatment when liquid
supersaturation becomes positive. The controlled saturation-adjustment
tests in Python support condensation treatment as a major contributor
to the model discrepancy.
